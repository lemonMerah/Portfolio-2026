## 📦 Project Info

- **Tech Stack:** HTML5, CSS3, JavaScript (ES6+)
- **Target Role:** Frontend Developer / Software Developer Intern

| Feature / Section | Description |
| :--- | :--- |
| **Hero Section** | Displays a brief introduction, educational background, and professional experience. |
| **Projects Section** | Showcases web portfolio and interactive game projects (Flappy Bird & Space Invader). |
| **Contact Section** | Complete contact information featuring click-to-copy functionality for WhatsApp and email, alongside direct links to LinkedIn and GitHub. |

## 📂 Files Description

```text
Portfolio-2026/
├── css/
│   ├── images/       <-- Contains portfolio images and project thumbnails
│   └── style.css     <-- Custom styling with glassmorphism theme
├── js/
│   └── script.js     <-- Interactive logic and auto-copy functionality
└── index.html        <-- Main portfolio page (Root Directory)
```
## 🎮 Features & Highlights

- Modern design featuring a **Glassmorphism** aesthetic and dynamic background animations.
- Fully responsive across various screen sizes and devices.
- Lightweight and interactive single-page navigation.
- Interactive auto-copy feature for contact details upon clicking.

## 🚀 How to Run Locally

1. Clone this repository to your computer:
   git clone https://github.com/lemonMerah/Portfolio-2026.git

2. Open the project folder in VS Code.
3. Run the `index.html` file using the **Live Server** extension in your preferred browser.
